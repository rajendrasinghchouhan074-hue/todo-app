# Todo App

A simple todo web app built with Python and Flask.

## Features

- Add, complete and delete tasks
- Set priority (High, Medium, Low)
- Set a due date, overdue tasks are highlighted in red
- Tasks are saved in a local `todos.json` file

## Setup

```
git clone https://github.com/rajendrasinghchouhan074-hue/todo-app.git
cd todo-app
pip install -r requirements.txt
python app.py
```

Then open http://127.0.0.1:5000 in your browser.
